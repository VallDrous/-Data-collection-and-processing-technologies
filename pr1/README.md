# Опис програмної реалізації  
Спочатку відбувається підключення всіх необхідних бібліотек для реалізації задачі:  
numpy для створення зручного масиву(матриці), він дозволить легко робити математичні операції та виконати формули, які необхідні для стандартизації.  
random для генерування рандомних даних.  
pandas для приведення даних у таблицю з якою можна зручно працювати.  

Спочатку у програмі відбувається створення даних у кількості 15000, які додаються в масив після чого даний масив перетворюється у масив numpy, що дозволяє зручно обчислити среднє значення та відхилення, які потрібні для стандартизації.
Після стандартизування знову обчислюється середнє та відхилення для перевірки(середні≈0 і std≈1). В кінці формується датафрейм в якому додається масив даних та стовбці після чого даний датафрейм виводиться у консолі.
