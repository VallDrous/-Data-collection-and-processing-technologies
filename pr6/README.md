# Завдання:  
Варіант 16: Дослідження впливу сонцезахисних окулярів на рівень освітленості.
Потрібно виміряти рівень освітленості через лінзи сонцезахисних
окулярів і порівняти цей показник з рівнем освітленості без них. Обробка
даних включає аналіз різниці в рівнях освітленості.

# Реалізація:  
Спочатку відбувається підключення необхідних бібліотек:  

pandas - для роботи з таблицями (Excel як DataFrame)  
matplotlib - для побудови графіків  

Після чого відбувається формування датафрейму на основі вхідного файлу, який містить результати вимірювань рівня освітленості як без використання сонцезахисних окулярів, так і з їх застосуванням.

Наступним кроком відбувається розділення даних перша половина - без окулярів, друга - з окулярами.  

Після цього обчислюються середні значення освітленості для кожної групи, визначається їх різниця, а також розраховується відсоток втрат освітленості.  

<p align="center"><img width="707" height="385" alt="image" src="https://github.com/user-attachments/assets/2da3930a-41dd-418c-8464-02b0fe70c27b" /></p>
