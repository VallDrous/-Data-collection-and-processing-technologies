# Завдання:  
Варіант 16: Використовуючи Faker, створіть набір випадкових даних для енергетичних показників(споживання, генерація) для різних типів споживачів (домогосподарства, підприємства).иОцініть коректність та корисність згенерованих даних для тестування алгоритмів прогнозування.  

# Реалізація:  

Спочатку відбувається підключення всіх необхідних бібліотек
1. pandas - бібліотека для роботи з табличними даними.
2. random - стандартний модуль Python для генерації випадкових значень.
3. math - стандартна бібліотека з математичними функціями.
4. Faker - бібліотека для генерації фейкових даних (імена, дати, адреси, числа).
5. train_test_split - функція з бібліотеки scikit-learn, яка розділяє дані на навчальну та тестову вибірки для навчання і перевірки моделі.
6. LinearRegression - алгоритм машинного навчання з scikit-learn, який використовується для побудови моделі лінійної регресії та прогнозування числових значень.
7. r2_score - метрика з scikit-learn, яка оцінює якість моделі регресії, показуючи наскільки добре модель пояснює залежність у даних.  

<p align="center"><img width="530" height="192" alt="image" src="https://github.com/user-attachments/assets/b09803dc-28fa-430f-88fc-a5763c911b63" /></p>  

Після підключення бібліотек створюється об'єкт класу Faker для генерації рандомних значень та у циклі відбувається створення елементів.У кожній ітерації випадково визначається тип споживача (household або enterprise) та генерується випадкова дата за останній рік. Далі обчислюється сезонний коефіцієнт на основі дня року за допомогою синусоїдальної функції, що імітує зміну споживання енергії протягом року. Також визначається добовий коефіцієнт залежно від години доби: у вечірній час споживання збільшується, у нічний - зменшується. Потім генерується базове споживання та генерація енергії, які відрізняються для домогосподарств і підприємств. На основі цих значень обчислюється підсумкове споживання енергії з додаванням невеликого випадкового відхилення. Усі отримані дані формуються у вигляді словника (ID споживача, тип, місто, дата і час, споживання та генерація енергії) і додаються до списку records. Після завершення циклу весь список записів перетворюється у таблицю DataFrame за допомогою бібліотеки pandas.    

<p align="center"><img width="831" height="775" alt="image" src="https://github.com/user-attachments/assets/f900f9d8-e663-4a1e-93e6-71a81eb6c82e" /></p>  

У наступному фрагменті спочатку виводяться перші рядки таблиці. Далі з колонки datetime створюються ознаки month і hour, а тип споживача перетворюється у числовий формат. Непотрібні колонки видаляються. Потім формується набір ознак X і цільова змінна y, після чого дані діляться на навчальну та тестову вибірки. Модель LinearRegression навчається на тренувальних даних, робить прогноз для тестових, а метрика r2_score оцінює точність моделі. Наприкінці виводиться значення R^2.
