# Завдання:  
Реалізувати “етичний” скрейпінг: перевірити robots.txt, обмежити частоту запитів,
додати таймаути і зібрати лог, який показує дотримання пауз між запитами.  
#
Спочатку відбувається підключення всіх необхідних бібліотек  
Це бібліотеки:  
1. requests - це бібліотека для відправки HTTP-запитів до сайтів і API.  
2. time - це стандартна бібліотека Python для роботи з часом і затримками.  
3. logging - бібліотека для логування подій у програмі.  
4. urllib.robotparser - модуль з стандартної бібліотеки Python, який читає файл robots.txt.  
<p align="center"><img width="458" height="106" alt="image" src="https://github.com/user-attachments/assets/418133aa-5cdc-4608-aa6a-26bae5b72be8" /></p>  

Спочатку відбувається перевірка, чи дозволено виконувати веб-скрейпінг сайту відповідно до правил файлу robots.txt. Спочатку за допомогою бібліотеки Requests виконується HTTP-запит до файлу robots.txt сайту Books to Scrape і виводиться його вміст. Далі створюється об’єкт RobotFileParser, який зчитує правила цього файлу. Після цього задається user_agent = '*' (будь-який бот) і URL сторінки, яку планується скрапити. Метод can_fetch() перевіряє, чи дозволено цьому боту отримувати дані з цієї сторінки. Якщо доступ заборонений — програма виводить повідомлення і завершується, якщо дозволений - повідомляє, що скрапінг можна виконувати.

<p align="center"><img width="589" height="431" alt="image" src="https://github.com/user-attachments/assets/565664fc-9c0a-4121-9fb3-1d42163a96c6" /></p>  

В наступному фрагменті через модуль logging задається запис логів у файл scraper.log з часом події. Змінні DELAY = 3 і TIMEOUT = 5 визначають затримку між запитами та максимальний час очікування відповіді сервера. У headers задається User-Agent це ідентифікатор бота, який відправляється разом із HTTP-запитами. Список pages містить URL сторінок сайту Books to Scrape, які скрейпер буде обробляти.  

<p align="center"><img width="607" height="455" alt="image" src="https://github.com/user-attachments/assets/ea3b2054-8305-4c2b-a077-b9585378ae2b" /></p>  

Далі по черзі обробляє сторінки зі списку pages. Для кожної сторінки спочатку фіксується час початку, після чого перевіряється через rp.can_fetch() чи дозволяє robots.txt сайту Books to Scrape доступ до цієї сторінки; якщо ні - записується попередження в лог і цикл переходить до наступної сторінки. Якщо доступ дозволений, за допомогою бібліотеки Requests виконується HTTP-запит requests.get() з переданими headers і timeout. У разі успіху виводиться статус відповіді та записується інформація в лог. Якщо виникає Timeout або інша помилка запиту, це також фіксується в логах. Після кожного запиту програма робить паузу time.sleep(DELAY), щоб не перевантажувати сервер, а потім обчислює загальний час виконання і записує його в лог.
